## 2.1. Функционально ПС поддерживает:

Функции администратора сервиса:
- Вход в систему под своей учетной записью;
- Добавление нового приложения в каталог с полным набором атрибутов (название, разработчик, описание, категория, цена, рейтинг, версия, размер, страна, возрастной рейтинг, скидка);
- Редактирование и удаление любого приложения каталога (удаление — с подтверждением);
- Восстановление исходного наполнения каталога (возврат к демонстрационным данным);
- Кнопки административных функций отображаются только для роли «Администратор».

Функции клиента:
- Вход в систему под своей учетной записью;
- Просмотр каталога приложений: подборка «Выбор дня», разделы по категориям, полный список всех приложений;
- Просмотр подробной карточки приложения (описание, разработчик, версия, размер, дата релиза, теги);
- Поиск по названию, разработчику, категории и тегам;
- Фильтрация: по цене, по рейтингу, по тегам, только установленные;
- Сортировка: по названию, по цене, по рейтингу, по дате релиза;
- Установка и удаление приложений (по одному нажатию кнопки, подпись меняется: «Установить» / «Открыть» / цена);
- Отмена и повтор действий установки/удаления (Undo/Redo);
- Управление профилем: просмотр и редактирование имени, фамилии, e-mail;
- Смена пароля;
- Переключение языка интерфейса (русский / английский) и темы оформления (светлая / тёмная).

## 2.2. При выполнении курсового проекта необходимо использовать принципы проектирования ООП. Приложение разрабатывается под ОС Windows и представляет собой настольное приложение (desktop) на платформе WPF (.NET 8). Отображение, бизнес логика должны быть максимально независимы друг от друга (MVVM). Диаграммы вариантов использования, классов реализации задачи, взаимодействия разработать на основе UML. Язык разработки проекта – C#. Управление программой должно быть интуитивно понятным и удобным. При разработке использовать два или более подходящих паттернов проектирования ПО: Repository (три взаимозаменяемых хранилища: JSON-файлы, PostgreSQL через ADO.NET и через Entity Framework Core), Command, Undo/Redo (история команд), Dependency Injection.
